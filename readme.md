## Présentation

Ce projet est un **site web statique responsive** servant de portfolio professionnel.  
Il met en avant mon parcours, mes compétences techniques, mes réalisations ainsi que mes informations de contact.

Le site intègre des animations modernes, des filtres dynamiques et une expérience utilisateur fluide.

---

## Fonctionnalités principales

- Navigation fluide avec menu sticky
- Animation de chargement (Splash Loader)
- Effets d’animation au scroll (AOS)
- Texte animé (Typed.js)
- Galerie d’images avec Lightbox
- Filtres dynamiques pour compétences et projets
- Slider d’équipe (Swiper.js)
- Design responsive (Desktop / Mobile)
- Formulaire de contact

## Structure du projet

  - `main.js` : logique JavaScript du site
